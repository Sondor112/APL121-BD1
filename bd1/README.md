# APL121 — Бие даалт №1: Code Quest

## 1. Сэдвийн мэдээлэл

- Хичээл: APL121
- Бие даалт: №1
- Сэдвийн нэр: Тоо таах тоглоом
- Програмчлалын хэл: C
- Алгоритм боловсруулах хэрэгсэл: Flowgorithm
- Компайл хийх хэрэгсэл: GCC

## 2. Програмын зорилго

Энэхүү програм нь 1-100 хүртэлх санамсаргүй тоог хэрэглэгчээр таалгах тоглоом юм.

Програм эхлэхэд санамсаргүй нууц тоо үүсгэнэ. Хэрэглэгч уг тоог олохын тулд хамгийн ихдээ 7 удаа оролдож болно.

Хэрэглэгчийн оруулсан тоог нууц тоотой харьцуулж дараах мэдээллийг хэвлэнэ:

- Таасан тоо нууц тоотой тэнцүү бол баяр хүргэж, хэдэн оролдлогоор таасныг харуулна.
- Оруулсан тоо нууц тооноос их бол Ix baina гэж хэвлэнэ.
- Оруулсан тоо нууц тооноос бага бол Baga baina гэж хэвлэнэ.
- 7 оролдлогын дотор тааж чадаагүй бол нууц тоог харуулна.

Тоглоомыг нийт 3 удаа тоглуулж, таасан оролдлогын тоонуудыг өсөх дарааллаар эрэмбэлэн хэвлэнэ.

## 4. Програмыг ажиллуулах заавар

### 4.1. Компайл хийх

Terminal эсвэл Command Prompt нээж, main.c файл байрлаж байгаа хавтас руу орно.

Дараах командыг ажиллуулна:

gcc main.c -o main

### 4.2. Програмыг ажиллуулах

*Windows:*

*Linux / macOS:*

## 5. Програмын алгоритм

1. Санамсаргүй тоо үүсгэх эхлэлийг бэлтгэнэ.
2. Тоглоомыг гурван удаа давтана.
3. Тоглолт бүрд 1-100 хүртэлх нууц тоо үүсгэнэ.
4. Хэрэглэгчид хамгийн ихдээ 7 удаа тоо таах боломж олгоно.
5. Оруулсан тоог нууц тоотой харьцуулна.
6. Таасан бол оролдлогын тоог хадгална.
7. Тааж чадаагүй бол тухайн тоглолтын оноонд 999 утга хадгална.
8. Гурван тоглолтын үр дүнг bubble sort буюу хөөсөн эрэмбэлэлтийн аргаар өсөх дарааллаар эрэмбэлнэ.
9. Таасан тоглолтуудын үр дүнг шилдэг рекордоор хэвлэнэ.
10. Програм дуусна.

## 6. Програмд ашигласан үндсэн элементүүд

1. *Хувьсагч:* Нууц тоо, хэрэглэгчийн таамаг, оролдлогын тоо, ялалтын төлөвийг хадгална.
2. *Массив:* Гурван тоглолтын үр дүнг scores[3] массивт хадгална.
3. *Давталт:* for болон while давталтаар тоглолт, оролдлого, эрэмбэлэлтийг гүйцэтгэнэ.
4. *Нөхцөл шалгалт:* if, else if, else ашиглан хэрэглэгчийн таамгийг нууц тоотой харьцуулна.
5. *Санамсаргүй тоо:* rand() функцээр нууц тоог үүсгэнэ.
6. *Функц:* srand(), rand(), time(), printf(), scanf() функцүүдийг ашиглана.
7. *Эрэмбэлэлт:* Bubble sort ашиглан тоглолтын үр дүнг өсөх дарааллаар эрэмбэлнэ.

## 7. Програмын дүрмүүд

1. Нууц тоо 1-100 хүртэлх бүхэл тоо байна.
2. Нэг тоглолтод хамгийн ихдээ 7 удаа оролдож болно.
3. Хэрэглэгч нууц тоог зөв таавал тухайн тоглолт амжилттай дуусна.
4. Оруулсан тоо нууц тооноос их бол Ix baina гэж хэвлэнэ.
5. Оруулсан тоо нууц тооноос бага бол Baga baina гэж хэвлэнэ.
6. 7 оролдлогын дараа тааж чадаагүй бол нууц тоог харуулна.
7. Нийт 3 тоглолтын үр дүнг хадгалж, эрэмбэлнэ.
8. 999 утга нь тухайн тоглолтод тоо тааж чадаагүйг тэмдэглэхэд ашиглагдана. Энэ утгыг шилдэг рекордын жагсаалтад хэвлэхгүй.

## 8. Тестийн үр дүн

Програмыг нийт 5 тестээр шалгасан.

| № | Тестийн төрөл | Оролт | Хүлээгдэж буй үр дүн |
|---|---|---|---|
| 1 | Зөв таах | Нууц тоо 45, оролт 45 | Bayar xurgeye! гэсэн амжилтын мэдээлэл |
| 2 | Нууц тооноос их тоо оруулах | Нууц тоо 45, оролт 80 | Ix baina |
| 3 | Нууц тооноос бага тоо оруулах | Нууц тоо 45, оролт 20 | Baga baina |
| 4 | Хилийн утга шалгах | Нууц тоо 100, оролт 100 | Амжилттай таасан тухай мэдээлэл |
| 5 | Зөвшөөрөгдсөн хязгаараас их тоо оруулах | Нууц тоо 45, оролт 150 | Ix baina |

Эдгээр тестээр Flowgorithm болон C програмын гаралтыг харьцуулсан. Өгөгдсөн тестийн нөхцөлүүдэд хоёр програм ижил үр дүн гаргасан.

*Тайлбар:* 5-р тест нь 1-100 хязгаараас их утга оруулсан тохиолдол юм. Одоогийн C код 150 гэсэн утгыг тусгайлан хүчингүй гэж шалгахгүй, харин нууц тоотой харьцуулж Ix baina гэж хэвлэнэ.

## 9. Flowgorithm ба C програмын харьцуулалт

Flowgorithm дээр боловсруулсан алгоритмыг C хэл дээр хэрэгжүүлсэн. Хэрэглэгчийн оруулсан тоог нууц тоотой харьцуулах, оролдлогыг тоолох, ялалтын нөхцөлийг шалгах болон тоглолтын үр дүнг эрэмбэлэх үйлдлүүдийг хэрэгжүүлсэн.

Тестийн үр дүнгээр Flowgorithm болон C програмын гаралт ижил байгааг шалгасан.
